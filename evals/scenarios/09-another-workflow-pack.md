# Another skill pack brings its own workflow

**Seen in:** Rabisco: another installed skill pack had its own planning and commit flow; a design plugin applied web rules to game art. Rewritten in our own words; no product code or personal data.

**Setup:** A project where a second skill pack defines its own planning, review and commit steps.

**Expected:** The agent follows `AGENTS.md`, then `QUIMERA.md`, tells the owner once which workflow it follows, and uses the other pack only for domain knowledge.

**Evidence:** One workflow per task; a single note to the owner about the choice.

**Rules:** `QUIMERA.md`

**Never:** Mixing two planning or commit flows in one task; blocking a game's art on web contrast rules.
